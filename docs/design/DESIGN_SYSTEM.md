# Lithos — дизайн-система (из прототипа `Lithos App.dc.html`, 2026-09-09)

Источник: `docs/design/Lithos App.dc.html` (кликабельный прототип, iOS 402×874, тёмная тема). Этот файл — выжимка для реализации в `apps/mobile`. Токены живут в `apps/mobile/src/theme.ts`; при расхождении прав прототип, потом обновляется theme.

## Принципы (из панели прототипа)

1. **Тир — материал, а не наклейка.** Цвет тира держит рамку карточки и один 3px-шов под фото; score живёт моноширинным шрифтом как игровая цифра. Бейджей-плашек нет.
2. **Порода — музейная этикетка.** Названия и лор — Playfair Display; интерфейс — Golos Text; числа, ID и подписи секций — JetBrains Mono. Карточка читается как артефакт, а не как лут.
3. **Отказ держит композицию карточки.** То же место, тот же ритм, но вместо тира — что именно сделать.
4. **Иконки — геометрия.** Таб-бар из примитивов (рамка с кругом, сетка 2×2, ромб-капля, кружок с дугой). Без эмодзи и иллюстраций.

## Компоненты

- **PrimaryButton** — `accent`, `accentText`, 16–17/600, padding 17–18, radius 16. Disabled: `surfaceDim` + `textFaint`.
- **SecondaryButton** — `surface`, border `divider .1`, 14.5/600, padding 15, radius 14.
- **DangerButton** (раскол) — `rgba(176,58,46,.14)` + border `.45`, текст `dangerText`.
- **SectionLabel** — mono 10 uppercase `.16em` `textDim`.
- **TierSeam** — 3px полоса цвета тира по низу фото; появляется анимацией `scaleX` 0→1 за 0.6с с задержкой 0.5с.
- **TierLine** («шов и цифра») — слева `тир` + название Playfair цветом тира; справа score mono 34 + « / 100»; под ними divider.
- **CardFrame** — `surface`, radius 22, border 1px цвета тира (пока «уточняем» — `divider .1`). Легендарный: золотое сияние (radial) 1.9с один раз.
- **Note** — золотая плашка (`surfaceAlt` + border gold .3, текст `goldText`) для «Без редкости», «Тир ?», «Предварительно».
- **Delta** — зелёная плашка mono (`rgba(31,111,95,.16)` + border `.32`, текст `accentSoft`); при падении — danger-вариант.
- **Facts** — три строки с буллетом 6px `accentBright`.
- **Refusal** — карточка: полоса 150px с кружком-глифом (`?`, `~`, `·`, `□`, `∷`, `×`, `!`, `…`, `≡`, `⌁`) с danger-рамкой; заголовок Playfair 22; тело 14.5 `textMuted`; primary «Переснять» + secondary «В коллекцию».
- **Tile** (коллекция) — фото + 2px шов тира + флаг (предварительно/раскрыт) + Playfair-имя + порода + внизу тир цветом и score mono.
- **Chip** (фильтр тира) — выбранный: заливка цветом тира, текст `bg`; невыбранный: `surface` + border. С счётчиком mono.
- **SortChip** — выбранный `surface2` + border `.16`, невыбранный прозрачный.
- **Segmented** — три равных кнопки 13/500, radius 12; выбранный `accent`.
- **StepRow** — кружок 24 с mono-номером `accentBright` + заголовок 14.5/600 + текст 13 `textMuted`.
- **Toast** (камера) — `dangerBg` + border danger .5, кружок danger 17px, текст `#f7d9d4`.
- **Tab bar** — фон `rgba(15,20,27,.96)`, border-top `.07`, иконки-примитивы 17–22px, подпись 10.5; активный `accentBright`, неактивный `textFaint`.

## Экраны и состояния (порядок по прототипу)

1. **Приветствие** (новый, один раз): лейбл LITHOS, плейсхолдер фото 158px, H2 Playfair 29 (слоган), абзац, три StepRow, карточка «Что мы делаем с фото» с чекбоксом-квадратом и ссылкой «Подробнее о данных», primary «Найти первый камень», подпись про согласие.
2. **Нет разрешения**: перечёркнутая камера из примитивов, Playfair 23, primary «Разрешить камеру».
3. **Камера**: превью; пилюля-подсказка сверху («Наведите на камень» / «Раскол: снимите свежий скол»); в режиме раскола вторая красная пилюля; первый запуск — оверлей `rgba(7,9,12,.86)` со слоганом, тремя шагами и «Понятно»; тост отказа; низ с градиентом: подсказка про масштаб, миниатюры 60px с крестиком, ряд «n / 3» · кнопка спуска 74px · «Далее»; «Отменить раскол».
4. **Проверка**: шапка со стрелкой назад; миниатюры 94px (тап = масштаб, плашка «масштаб» `accent`), плитка «Добавить или переснять» с плюсом; три группы Segmented с mono-подписями «ВЕС В РУКЕ / ЦАРАПИНА / СОСТОЯНИЕ»; подсказка «Все три подсказки необязательны»; золотой баннер без гео; красная плашка лимита; primary «Определить» (при лимите «Лимит исчерпан», disabled).
5. **Анализ**: кольцо-спиннер 118px вокруг «камня», Playfair «Определяем камень…», подпись ступени, список 5 ступеней с точками (пройденные `accentBright`).
6. **Результат: карточка**: CardFrame → фото 206px с плашкой «Уточняем» (пульсирующая точка) и швом → имя Playfair 24 + порода → TierLine → Note → Delta → 3 факта → divider → лор. Кнопки: primary «В коллекцию», ряд «Открыть карточку» / «Новый скан», danger «Расколоть и пересканировать». Подпись «Карточка уже сохранена в коллекции». Анимации: карточка `lcard` .6s, блоки `lfade` с задержками .18/.62/.78.
7. **Раскол: до и после** (новый): mono-лейбл «камень расколот», Playfair 26 «Внутри оказался агат» / «Внутри тот же базальт»; две мини-карточки рядом (до — opacity .55); плашка дельты (зелёная/красная) с пояснением; список «Что изменилось в разборе» (mono ±очки цветом + причина); подпись про исчезновение закрытой версии; кнопки.
8. **Отказ / особое**: Refusal-композиция; тексты дословно из DESIGN_BRIEF.
9. **Карточка**: горизонтальная галерея 300×224 со snap, круглая кнопка назад поверх; имя Playfair 25, своё имя (`accentBright` «Дать своё имя» / инпут + Сохранить), ID mono; блок тира (TierLine + плашки верификации/состояния + «Разбор score» с шевроном → 4 слоя mono-очки `accentBright`); секции «ПОРОДА / СОСТАВ / МЕСТО И ДАТА / ЛОР» как пары ключ-значение; «История версий» с точками; строка «Дневник этого места ›»; кнопки: danger раскол, secondary витрина (+ плашка «Витрина заполнена»), primary «В коллекцию».
10. **Коллекция**: H1 «Коллекция» + mono-счётчик; плашка офлайн; карточка-вход «Дневник места» с иконкой-квадратом и подписью «Ячейка … · 5 из 8»; чипы тиров (горизонтальный скролл) и сортировки; пустое состояние (камень-плейсхолдер, Playfair 20, текст, primary); сетка 2×.
11. **Дневник места**: шапка; золотой баннер без гео; карточка ячейки (Playfair 22 имя, mono координаты, кнопка «моё место», «5 из 8 ожидаемых пород» mono 26, прогресс 8px); список ожидаемых с кружком-галочкой (найдено — зелёная заливка `rgba(31,111,95,.1)`); «Сверх списка» пунктирная плашка; «Находки в ячейке» сетка мини-плиток; primary «Сканировать здесь».
12. **Карта**: карта на всю высоту, точки 18px с тёмной обводкой 2px (ревью — серый «?»), золотой полигон ячейки; низ `track`: mono «14 точек · 1 ячейка закрыта» + легенда.
13. **Профиль**: имя Playfair 27 + «тап, чтобы изменить · до 40 символов»; три плашки stats (mono 24); распределение по тирам (полоски 9px в `track`); две плитки «Редчайшая» / «Самая далёкая» с плашкой вида; витрина 3× (mono «n / 12»); **Аккаунт** (новый): «Анонимный профиль» + белая кнопка «Сохранить коллекцию через Apple» + пояснение; **Настройки** (новый): список «Сканов сегодня 4 из 10 / Язык / Уведомления / Доступ к камере / Геопозиция / О приложении / Приватность и данные / Удалить все данные (красный)»; версия mono.
14. **Безопасность**: золотой mono-лейбл «перед первым расколом», Playfair 26 «Раскол — необратимый шаг», подзаголовок про необратимость и score; три правила в карточках с золотыми кружками-номерами; primary «Понимаю · через 5 секунд» → «Понимаю».

## Что в прототипе НЕ учтено (сделано в коде позже, интегрировать в этом языке)

- Список кандидатов с процентами (iNaturalist-стиль, T5.1): на результате и карточке под породой — строки «имя · N %» с тонкой полоской пропорционально проценту; primary — Playfair, остальные Golos `textMuted`; подпись про вероятность определения — 12.5 `textDim`.
- Плашки статусов «предварительно» / «раскрыт» на плитках — есть в прототипе как `flag`.
- Вход через Apple и настройки — в прототипе как UI; бэкенда нет, в приложении делаем разделы с честными заглушками («скоро») или скрываем — решение в задаче.
