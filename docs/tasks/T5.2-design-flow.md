## Что сделано в этой сессии

### `screens/ResultScreen.tsx` — полный рестайл, логика данных не тронута
Все хуки/эффекты (`useScanWatch`, 90-секундный таймер, `scan_results` запасной путь, `identification`,
родительская карточка, `isCardCollected`) перенесены один в один. Заменена только композиция рендера:

- **Отказы и особые состояния** (`failed`, `budget_paused`, ошибка сети, `slow`/`gaveUp`) — через новый
  универсальный переходник `RefusalAction → handler` (`retake/collection/rescan/refresh`) и компонент `Refusal`,
  вместо руками свёрстанных `<View><Text>`. Ошибка сети показывает уже санитизированный `error` (из
  `toUserMessage`, без текста сервера) в композиции «Нет связи» (глиф `⌁`).
- **Загрузка** — компонент `Analyzing` (кольцо + 5 ступеней) вместо `ActivityIndicator`. Кнопка «Новый скан»
  снизу — подстраховка от зависшего анализа: в прототипе её нет на этом экране, но `Safety`/`Result` здесь без
  свайпа назад и без хедера, оставлять пользователя совсем без выхода не стал; зафиксировано как осознанное
  отступление.
- **Карточка результата** — `CardFrame` (рамка цвета тира, во время `refining` — нейтральная, как в прототипе)
  → фото 206px (реальное, `fetchScanPhotos` + `expo-image`, с фолбэком на `PhotoPlaceholder`) → плашка
  «Уточняем» с пульсирующей точкой (`Animated`, как `lpulse`) → имя Playfair 24 → `IdentificationList` (было
  готово, T5.1) → `TierLine` → `Note` (без редкости / тир на ревью / предварительно) → `DeltaPill` (дельта
  раскола, запасной путь на случай если Compare не сработал) → `IdentificationNote` → три `FactRow` → лор.
  Легендарный тир — `LegendaryGlow` (новый примитив в `ui.tsx`, см. ниже).
- **Раскол завершён** (`phase==='done' && parentId && parent && state==='opened'`) — вместо обычной карточки
  рендерится `CompareCard` (см. ниже), это и есть «экран 7» прототипа. Инлайновая дельта в обычной карточке
  оставлена как fallback на случай, если `parent` почему-то не загрузился.
- Убрана нюансовая подпись «Проверяем вердикт второй моделью / Досчитываем редкость» под тиром (была в
  дообразцовом коде, в прототипе её нет) — упрощение ради точного соответствия макету; плашка «Уточняем» на
  фото остаётся единственным индикатором.

### `components/CompareCard.tsx` — новый (экран 7 «Раскол: до и после»)
Не навигационный экран, а компонент, подставляемый в `ResultScreen` — так чтобы не дублировать
watch/fetch-логику скана в отдельном роуте (в `RootStackParamList` роут `Compare` не заводился, это
сознательное решение, отличное от исходной формулировки задачи «CompareScreen»). Данные — чистая функция
`compareCards(parent, child)` из `lib/compare.ts` (была готова: заголовок с правильным родом
«оказался/оказалась/оказалось», список изменений по слоям, пояснение под дельтой). Композиция: mono-лейбл
«камень расколот» → Playfair 26 заголовок → две мини-карточки (до — `opacity .55`, шов и тир) → `DeltaPill` с
пояснением → список «Что изменилось в разборе» (±очки mono цветом, причина) → сноска про исчезновение закрытой
версии → кнопки («Открыть карточку» primary, «В коллекцию»/«Новый скан» secondary в ряд).

### `screens/SafetyScreen.tsx` — полный рестайл
Было: эмодзи-иконки, `fontWeight` без `fontFamily`, вне токенов. Стало: gold `SectionLabel` «перед первым
расколом», Playfair 26 «Раскол — необратимый шаг», подзаголовок, три `StepRow` с `tone="gold"` (кружки-номера
1/2/3 на золотом), кнопка «Понимаю» (активна через 5 с, подпись обратного отсчёта через `pluralRu` — «через 5
секунд» → «через 1 секунду», а не статичный текст мокапа, поскольку в приложении это живой таймер). Добавлена
кнопка «Отмена» (`variant="ghost"`) — в прототипе кнопки отмены на этом экране нет вообще (только «Понимаю»),
но экран открывается с `gestureEnabled: false` и без хедера, и без единственной кнопки пользователь, передумавший
раскалывать камень, был бы заперт на экране до истечения таймера с последующим принудительным подтверждением.
Сохранил именно возможность уйти, а не увеличивать степень принуждения сверх прототипа. Помечено как осознанное
отступление, а не пропуск.

### `components/ui.tsx` — добавлен `LegendaryGlow`
Прототип использует CSS `radial-gradient` + keyframe `lhalo` (0→.6→0 за 1.9с, задержка .45с) для золотого сияния
легендарной карточки. React Native не умеет radial-gradient без `expo-linear-gradient` (в проекте сознательно не
используется, см. комментарий в `CameraScreen.tsx`); приближено тремя вложенными полупрозрачными кругами
убывающей плотности с той же анимацией через `Animated.sequence`. Проигрывается один раз на смену `replayKey`
(id карточки).

## Решения (кратко, подробности — по разделам выше)
1. Compare — компонент внутри ResultScreen, не отдельный роут (не дублируем watch/fetch).
2. Refusal actions — единая таблица `RefusalAction → handler`, вместо разбросанных `onPress`.
3. Убрана нюансовая под-подпись refining-статуса (упрощение к прототипу).
4. `LegendaryGlow` — приближение radial-gradient стопкой кругов, без новой зависимости.
5. `SafetyScreen` — добавлена кнопка «Отмена» сверх прототипа (не запирать пользователя).
6. `ResultScreen` (analyzing) — добавлена ghost-кнопка «Новый скан» сверх прототипа (та же причина).
