# T3.2 — Клиент: карта

Статус: **код готов, ревью APPROVE (minor закрыты), проверки зелёные; ждёт ручной проверки на телефоне (iOS)** · 2026-09-08

## Что сделано

Вкладка **Карта** (spec §8 «Мировой атлас», dev-plan T3.2): точки сканов пользователя цветом тира, тап → карточка,
ячейки geohash-6 с полностью закрытым дневником подсвечены полигоном, офлайн — точки из кэша.

### Файлы (`apps/mobile/src/`)
- `screens/MapScreen.tsx` — **новое**. `react-native-maps` (`MapView` + `Marker` + `Polygon`), без провайдера
  (iOS — Apple Maps без ключа). Точки — карточки `hidden=false` с `lat/lng`, маркер — кружок цвета тира
  (`tierColor`, `pending_review` — серый «?»), `tracksViewChanges={false}`, `title/description` = имя и тир,
  `onPress` → `Card`. Полигоны — `completedCells(diary, cards)` → `cellPolygon(cell)` (только geohash-6), цвета
  подсветки — `theme.mapColors`. Стартовый регион — `boundingRegion(points)` (bbox точек с запасом, потолок дельт,
  антимеридиан), без точек — Черноморское побережье; после `onMapReady` — `fitToCoordinates`, и снова — когда набор
  точек изменился (новый скан). Легенда снизу: число точек и закрытых ячеек, цвета тиров;
  пустое состояние «Пока нет точек → Сканировать»; баннер «Нет связи — показаны сохранённые точки».
- `lib/geohash.ts` — `decodeBbox` / `cellPolygon` (см. T3.1), `lib/geo-math.ts` — `boundingRegion`, `lib/text.ts` —
  `pluralRu` (легенда «N точек / ячеек закрыто»).
- `lib/offline-cache.ts` — `loadCards()` / `loadDiary()` с кэшем AsyncStorage при каждой загрузке (см. T3.1).
- Тесты: `geohash.test.ts` (bbox/полигон, сверка с ngeohash), `geo-math.test.ts` (`boundingRegion`: запас,
  потолок дельт, антимеридиан Чукотка–Аляска), `text.test.ts` (`pluralRu`), `diary.test.ts` (`completedCells`).

## Проверка

Автоматически (зелёные): `pnpm --filter mobile typecheck`, `pnpm --filter mobile test`, `pnpm lint`,
`npx expo export --platform ios`.

### На телефоне
1. Вкладка «Карта»: точки в местах сканов — сверить с `lithos.cards.lat/lng` в Table Editor (приёмка «точки
   соответствуют координатам сканов»); цвет кружка = тир карточки (легенда снизу).
2. Тап по точке → карточка; «назад» → карта.
3. Закрыть дневник ячейки (все ожидаемые породы найдены) → ячейка подсвечена золотым прямоугольником, в легенде
   «1 ячейка закрыта».
4. Выключить сеть, перезайти на вкладку → точки на месте (кэш) и баннер «Нет связи»; тайлы карты — только те, что
   Apple Maps успел закэшировать сам.

## Решения
- **react-native-maps, не MapLibre** — по условию: без нового нативного модуля; в Expo Go и dev-сборке на iOS
  работает без ключей.
- **Android**: Google Maps требует API-ключ (`app.json → android.config.googleMaps.apiKey`, в dev-сборке);
  без него тайлы не рисуются (маркеры/оверлеи — да). В Expo Go на Android карта обычно показывается на ключе
  самого Expo Go, но это не гарантируется. Ключ в `app.json` — публичный для клиента, но ограничивать его по
  package name/SHA-1 в Google Cloud; пока не добавлен — на этом этапе проверяем iOS.
- **Маркер — свой View, а не `pinColor`**: `pinColor` на Android квантуется до ближайшего hue, цвета тиров
  расплываются; кружок одинаков на обеих платформах.
- **Подсветка только полностью закрытых ячеек** (dev-plan T3.2). Spec §8 «регионы раскрашиваются по полноте
  дневника» — градация по проценту не делалась (см. ниже).
- **Офлайн — данные, не тайлы**: кэшируем карточки и дневник; офлайн-тайлы (`LocalTile`) вне прототипа.
- **Стартовый регион** — bbox точек; `fitToCoordinates` один раз после готовности карты, чтобы не дёргать
  пользователя при каждом фокусе.

## Не сделано / открытое
- **Не проверено на телефоне**; **Android без ключа Google Maps — карта пустая** (тайлов нет, маркеры есть). Нужен ключ
  от человека: `app.json → android.config.googleMaps.apiKey` (ограничить по package name + SHA-1) — до APK-сборки T4.2.
- **Точки — только из `cards`** (`lat/lng` карточки): сканы без карточки (отказ, в обработке, `budget_paused`) на карте
  не видны; spec §8 говорит о местах сканирования — при необходимости добавить слой по `scans`.
- Градация ячеек по полноте дневника (частично закрытые), кластеризация точек при сотнях карточек.
- Ячейки в дневнике/карте появляются только после первого скана в них (строка `lithos.diary` пишет воркер).
- Кнопка «моё местоположение» — только системная синяя точка (`showsUserLocation`); на iOS видна, если
  разрешение на гео уже дано при скане.
- В git не коммичено (по условию задачи).
