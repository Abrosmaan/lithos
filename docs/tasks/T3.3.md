## Что сделано

Вкладка **Профиль** (spec §8 «Статистика», «Витрина»; §12 экран 6; dev-plan T3.3): имя (редактируется,
`lithos.users.display_name`), сканов всего, распределение по тирам, редчайшая карточка, самая далёкая находка,
витрина до 12 карточек (локальный выбор, без шеринга). Anon-auth и строка `users` — из T1.4 (`ensureUser`).

## Проверка

Автоматически (зелёные): `pnpm --filter mobile typecheck`, `pnpm --filter mobile test`, `pnpm lint`,
`npx expo export --platform ios`.

### На телефоне — «цифры совпадают с БД»
1. Профиль → «Сканов» = `select count(*) from lithos.scans where user_id = <id>` (SQL Editor; `<id>` — своя строка
   `lithos.users`).
2. «Карточек» и полоски = `select tier, count(*) from lithos.cards where user_id = <id> and hidden = false group by tier`
   (`tier is null` → «Без редкости»).
3. «Редчайшая» = `... order by score desc nulls last, created_at asc limit 1`.
4. «Самая далёкая»: первая по `created_at` карточка с координатами — точка отсчёта; расстояние до остальных —
   haversine; в профиле показана максимальная (для проверки — `earth_distance`, если расширение есть, или
   прикинуть по карте).
5. Имя: тап → ввести → «Сохранить» → в Table Editor `users.display_name` обновился; пустое имя сбрасывает в `null`
   и показывается «Собиратель камней».
6. Витрина: на карточке «В витрину» → в профиле плитка; 13-я → Alert; «Убрать из витрины» — исчезает.
   Витрина хранится локально (AsyncStorage), после переустановки — пустая.

## Решения
- **Хранение витрины локально** — dev-plan T3.3: «витрина локальная, без шеринга»; колонка в БД не добавлялась
  (границы задачи — только `apps/mobile`).
- **«Сканов всего» — по `scans`** (включая отказы и расколы), «Карточек» — по видимым `cards`; распределение по тирам
  и редчайшая — по видимым (`hidden=false`): родитель после раскола — тот же камень, не двойная находка.
- **Самая далёкая — от первой находки** (а не максимальная пара): O(n), объяснимо пользователю
  («X км от первой находки»).
- **Имя — через `users.id`** из `ensureUser()` (строка гарантированно есть), не через `auth_user_id`.
- Имя/счётчик офлайн не кэшируются отдельно: без сети показываются последние загруженные значения или «—»;
  карточки — из общего кэша.

## Не сделано / открытое
- **Не проверено на телефоне.**
- Плашка «Ячеек» (число ячеек с находками) — сверх spec §8; оставлена как дешёвая и полезная, убрать — одна строка.
- «Самая далёкая» считается по видимым карточкам: точка отсчёта — первая находка **без** скрытых родителей после
  раскола; если первая находка была расколота, отсчёт сдвигается на следующую.
- Витрина «видна другим» (spec §8) — шеринг вне прототипа (dev-plan §0); порядок в витрине — порядок добавления,
  перестановки нет.
