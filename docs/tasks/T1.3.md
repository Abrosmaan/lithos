## Что сделано

`apps/worker/src/llm/` — `callModel(input, deps?) → CallModelOutput` через Vercel AI SDK (`ai@7`, `@ai-sdk/anthropic@4`, `@ai-sdk/google@4`):

| Файл | Что |
|---|---|
| `config.ts` | `parseModelSpec('provider:model')`, `loadLlmConfig(env)` (STAGE_GATE / STAGE_MAIN / STAGE_ESCALATION / FALLBACK_PROVIDER, дефолты из dev-plan §6; **ключей в конфиге нет**), `ROLE_MODELS` (модель по роли ступени у каждого провайдера — для fallback), `MODEL_PRICES` ($/1M), `estimateCostUsd`, таймауты `STAGE_TIMEOUT_MS` (gate 20 с, main 30 с, escalation 45 с), `RETRY` (исходный вызов + 3 ретрая = 4 HTTP-вызова, backoff 1/2/4 с + jitter ≤ 0.5 с). Чистые функции, без чтения .env. |
| `providers.ts` | Единственное место с ключами API: `createModelResolverFromEnv(env)` / `createModelResolver(keys)` — `createAnthropic` / `createGoogleGenerativeAI` лениво, ключ отсутствует → `MissingApiKeyError`; `hasApiKey(provider)` для smoke. `providerOptionsFor(spec, stage)`: Google — `thinkingConfig.thinkingLevel` минимальный (`minimal`; для Flash ≥ 3.7 — `low`, ниже SDK/API не принимает), `includeThoughts:false`; Anthropic — main `{thinking:adaptive, effort:'low'}`, escalation `effort:'medium'`, gate/Haiku — ничего. |
| `prompts/gate.ts`, `prompts/main.ts`, `prompts/escalation.ts` | Тексты дословно из ai-pipeline §6, `PROMPT_VERSION = 'gate-v1' / 'main-v1' / 'escalation-v1'`. | `breaker.ts` | `CircuitBreaker` на провайдера: скользящее окно 60 с, > 25 % ошибок при ≥ 4 вызовах → open на 2 мин → half-open с 10 % пробных; успех пробы → closed, провал → open. `onSchemaFailure()` — невалидный вывод учитывается как вызов (знаменатель), не как ошибка. `forceOpen/forceClose`, `stats()` для мониторинга. `BreakerRegistry` — один breaker на провайдера на процесс. |
| `callModel.ts` | Логика ai-pipeline §7: `generateText` + `Output.object({schema})` со схемой из `@lithos/shared` (`GateResultSchema` / `ScanResultSchema`), `maxRetries:0` (retry наш). 429/529/408/5xx/timeout/сетевые → до 3 ретраев с backoff, каждая ошибка в breaker; breaker открылся посреди retry → сразу fallback. Невалидный JSON/схема/пустой вывод (`NoObjectGeneratedError`, `NoOutputGeneratedError`) → один repair-вызов той же модели (есть сырой текст → диалог user → assistant(сырой) → user «Fix this output to match the schema, change nothing else.»; текста нет → один повторный запрос) → неудача → fallback. 4xx (кроме 408/429) → без retry, сразу fallback. Неожиданная ошибка не из §7 → тоже fallback, при его отказе пробрасывается исходная. Fallback: второй провайдер, модель той же роли (`fallbackSpec`). `fallbackReason: 'none' \| 'no_api_key' \| 'breaker_open' \| 'provider_error' \| 'schema_invalid'`; `usedFallback=true` только при реальном отказе (последние три) — по нему S4 ставит «предварительно» и режет тир; `no_api_key` = провайдер не сконфигурирован: `usedFallback=false`, warn один раз на процесс. Оба отказали → `LlmUnavailableError{stage, attempts, causes:[{provider, model, kind, message≤200}]}` — без сырых ошибок SDK (в них тело запроса с base64 фото). Каждый успешный вызов — `log.info('llm call', {scan_id, stage, provider, model, prompt_version, tokens_in, tokens_out, cache_read_tokens, cache_write_tokens, cost_usd, latency_ms, attempts, used_fallback, fallback_reason, repaired})`. Конфиг — `config.llm` из `apps/worker/src/config.ts` (один источник, он грузит .env); `sleep`, `now`, `random`, `resolveModel`, `breakers`, `log`, `noKeyWarned` инжектируются через `deps`. |
| `types.ts`, `index.ts` | `CallModelInput` / `CallModelOutput` / `FallbackReason` / `ImageInput`; публичный баррел для T2.x, первым импортирует `../config.js` (нет ловушки с порядком импортов). |

## Решения

- **Model id.** Anthropic — из skill `claude-api`: `claude-haiku-4-5`, `claude-sonnet-5`, `claude-opus-5` (без датированных суффиксов). Google — из ai-pipeline §2a: `gemini-3.1-flash-lite`, `gemini-3.7-flash`, `gemini-3.1-pro`. В типах `@ai-sdk/google@4` для 3.1 перечислены `-preview`-варианты (`gemini-3.1-flash-lite-preview`, `gemini-3.1-pro-preview`) — если GA-id не существует, поменять STAGE_*/`ROLE_MODELS` после smoke с ключом.
- **Цены.** Haiku 4.5 $1/$5 и Opus 5 $5/$25 совпадают в skill и §2a. **Sonnet 5: skill (кэш 2026-06-24) даёт $2/$10, ai-pipeline §2a — $3/$15 «с 1 сентября 2026 (вводные закончились)». Взял $3/$15** — источник истины новее и явно описывает переход. Prompt cache Anthropic: чтение ×0.1, запись (5 мин) ×1.25 от input — из skill. Google: только input/output; thinking-токены уже входят в `outputTokens`; вводные цены до 31.12.2026 (§2a). Неизвестная модель → `cost_usd=0`, `price_known=false` в логе.
- **Стоимость** считается по `usage` SDK: `inputTokenDetails.noCacheTokens × input + cacheReadTokens × cacheRead + cacheWriteTokens × cacheWrite + outputTokens × output`; `tokensIn` в выходе — сумма всех входных. При repair токены обоих вызовов суммируются. Неуспешные HTTP-вызовы usage не дают.
- **Prompt cache.** `cacheControl` стоит на системном сообщении Main (и первом блоке Escalation). Smoke показал `cache_write=3883` при системном промпте ~600 токенов — в кэшируемый префикс у Anthropic попадает и схема structured output, что и даёт объём выше минимального порога кэширования. `{user_language}` подставляется в системный промпт → отдельный кэш на язык (2 языка — приемлемо). Геоконтекст (§3 «cache на ячейку») не кэшируется — он в user-сообщении и меньше минимального порога; отложено.
- **Thinking (Anthropic).** По skill `claude-api`: `budget_tokens` на Sonnet 5 / Opus 5 **отвергается с 400** (принимается только на ≤ 4.6), а `thinking:{type:'disabled'}` на Opus 5 имеет побочные эффекты (утечка тегов в текст). Поэтому ограничиваем adaptive thinking через `effort`: main → `low`, escalation → `medium`, gate (Haiku 4.5 — `effort` там → 400) — без опций. Guard `supportsAnthropicEffort(model)`: опции ставятся только для Sonnet/Opus 4.6+/5, чтобы `STAGE_MAIN=anthropic:claude-haiku-4-5` не ломался. Подтверждено smoke (см. «Smoke после ревью», `effort:'low'` на Sonnet 5 принят). Google — `thinkingLevel` минимальный по §2a.
- **Fallback по роли ступени, а не «всегда Gemini 3.1 Pro»** (§7 написан для полностью-Anthropic стека; §2a говорит, что при смешанном стеке fallback «меняется зеркально»). `fallbackSpec`: если основной провайдер ступени уже равен `FALLBACK_PROVIDER`, берётся противоположный — fallback всегда другой провайдер. Ограничение тира Rare и статус «предварительно» для `usedFallback` — в S4 Rules (T2.x), здесь только флаг.
- **`generateText` + `Output.object`** вместо `generateObject` — последний в `ai@7` помечен `@deprecated`. Картинки — `file`-part с `mediaType` (`image`-part deprecated).
- **Escalation-добавка — вторым системным блоком**, не в тексте user: первый системный блок остаётся стабильным кэшируемым префиксом, а вердикт S2 меняется на каждый скан.
- **Breaker проверяется и между retry**: если провайдер открылся на текущей ошибке, оставшиеся попытки не тратятся — сразу fallback. Схемные ошибки (невалидный JSON / пустой вывод) — провайдер ответил, это не отказ: учитываются в знаменателе breaker'а (`onSchemaFailure` → вызов), не в числителе.
- **Ключи API** живут только в `providers.ts` (`createModelResolverFromEnv`), в `config.llm` их нет — нечего случайно залогировать/сериализовать.
- **`no_api_key` ≠ отказ.** Если основной провайдер ступени не сконфигурирован (сейчас — Google без ключа), ответ второго провайдера — штатный, не «предварительный»: `usedFallback=false`, `fallbackReason='no_api_key'`, один warn на процесс. `usedFallback=true` только при `breaker_open` / `provider_error` / `schema_invalid`.
- **4xx кроме 408/429 — без retry** (повтор того же запроса бесполезен), но fallback пробуется: он дёшев и покрывает случай, когда 400 вызван провайдер-специфичным ограничением схемы.
- Прямая зависимость `@ai-sdk/provider` в `apps/worker/package.json` не добавлялась (нельзя править): типы для моков выведены из `MockLanguageModelV4`, `ProviderOptions` — из сигнатуры `generateText`.

## Отклонения от spec/плана (dev-plan §5 п.1)

- **Имя переменной ключа Google:** dev-plan §6 называет `GOOGLE_API_KEY`, в коде и `.env.example` (T0.1) — `GOOGLE_GENERATIVE_AI_API_KEY` (имя, которое читает `@ai-sdk/google` по умолчанию). Оставлено `GOOGLE_GENERATIVE_AI_API_KEY`; при заполнении `.env` использовать его.
- **Breaker: порог ≥ 4 вызовов в окне (`minCalls`)** — сверх ai-pipeline §7 («> 25 % за 60 с»). Без него один первый неудачный вызов (1/1 = 100 %) открывал бы breaker на 2 минуты. Число — в `BREAKER_DEFAULTS`, тест «stays closed below 4 calls».
- **Fallback по роли ступени**, а не фиксированный Gemini 3.1 Pro (§7) — см. «Решения».
- **Sonnet 5 $3/$15** (ai-pipeline §2a) вместо $2/$10 из кэша skill — см. «Решения».
