# ТЗ: Lithos (рабочее название) — игра про поиск и коллекционирование камней

Версия 0.1 · 5 сентября 2026

---

## 1. Суть

Игрок находит камень, фотографирует, получает AI-вердикт о породе и составе, а камень превращается в карточку с редкостью и score. Дальше — по желанию: коллекция по регионам, обмен, отправка на оценку, рынок.

Одна фраза для стора: «Каждый камень под ногами — карточка с историей в миллионы лет».

Референсы и что берём:
- **Merlin Bird ID** — мгновенное определение по фото/звуку, честная вероятность вместо ложной точности, региональный контекст сужает варианты.
- **iNaturalist** — сообщество подтверждает определения, «исследовательский» статус наблюдения достигается консенсусом.
- **Pokémon GO** — коллекция как самоцель, привязка к физическому перемещению, редкость как драйвер.
- **Pokémon card grading (PSA)** — физический объект → сертифицированная оценка → ликвидный актив.

---

## 2. Аудитория и сегменты

Три уровня вовлечения, каждый следующий — необязательный.

| Сегмент | Мотивация | Что ему нужно |
|---|---|---|
| Сканер | «Что это за камень?» | Быстрый ответ, лор, ноль друзей и регистрации |
| Коллекционер | Заполнить дневник региона, редкие карточки | Коллекция, редкость, прогресс, дневник по местам |
| Трейдер | Ценность, статус, ликвидность | Grading, рынок, NFT, репутация |

Первичный рынок: туристы на галечных пляжах, семьи с детьми, хайкеры, rockhound-сообщества (США/Австралия/UK — крупные и платёжеспособные).

---

## 3. Core loop

```
Найти → Сканировать → Получить карточку → (Расколоть → Пересканировать) → В коллекцию → Подтвердить сообществом → Обменять / Отправить на оценку
```

Короткий цикл (1–2 мин): скан → карточка.
Средний цикл (день): прогулка, 5–20 сканов, заполнение дневника локации.
Длинный цикл (недели): редкие тиры, grading, рынок.

---

## 4. Сканирование

### 4.1 Вход
- 1–4 фото камня (обязательно одно с масштабом: монета/палец, приложение подсказывает).
- Геопозиция (обязательна для карточки с редкостью; без гео — только определение, карточка без score).
- Опционально: вес (пользователь вводит «тяжелее/легче обычного» тремя кнопками), мокрый/сухой, тест царапания ногтем/монетой (три кнопки). Каждый ответ повышает confidence и даёт мини-бонус к score.

### 4.2 Обработка
1. Геоконтекст: по координатам подтягивается литология региона (см. §11) — какие породы здесь ожидаемы, какой водосбор, есть ли рядом обнажения.
2. Vision-модель получает фото + геоконтекст + ответы пользователя и возвращает **структурированный JSON**:
   - `rock_class` (категория: базальт/андезит/серпентинит/яшма/…) + `confidence`
   - `inclusions[]`: минерал, `confidence`, `extent` (следы / заметно / основной)
   - `shape_tags[]`: сферический / плоский / с отверстием / асимметричный / …
   - `surface`: окатан / свежий скол / выветрен
   - `notes`: 2–3 предложения лора для карточки
   - `split_recommended`: bool + причина
3. Правила игры (не модель) считают score и тир по §6.

### 4.3 Выход
Экран результата за ≤ 5 секунд: название, тир, три главных факта, кнопка «в коллекцию», кнопка «расколоть и пересканировать» (если рекомендовано).

Принцип: **модель даёт вердикт с вероятностью, игра даёт цифры.** Score никогда не берётся напрямую из confidence — только через дискретные пороги. Иначе один и тот же камень при пересъёмке будет менять редкость.

---

## 5. Карточка камня

Поля:
- Имя (автоген: «Миндалекаменный базальт, Гонио») + пользовательское имя
- Тир редкости + числовой score
- Фото (лицевая — лучшее фото, обратная — скол, если есть)
- Порода, состав (список включений с бакетами, без процентов)
- Место и дата, «геологический возраст региона» (диапазон, из карты)
- Лор (2–3 предложения)
- Статус верификации: AI / подтверждено сообществом / оценено экспертом
- Уникальный ID = хэш(фото + гео + время + user_id)
- Состояние: закрытый / раскрытый (расколот)

Карточка живая: после раскола, подтверждения или grading она обновляется, история версий видна.

---

## 6. Редкость и score

Сумма четырёх слоёв, максимум 100. Тиры по порогам:

| Тир | Score |
|---|---|
| Обычный | 0–29 |
| Необычный | 30–49 |
| Редкий | 50–69 |
| Эпический | 70–84 |
| Легендарный | 85–100 |

### 6.1 Форма (0–25)
По `shape_tags` из модели, таблица фиксирована:
- Идеально окатанный сфероид / яйцо — 8
- Сквозное естественное отверстие («куриный бог») — 20
- Узнаваемый силуэт (сердце, полумесяц) — 15
- Полосчатость / рисунок на поверхности — 10
- Обычная галька — 3

### 6.2 Соответствие месту (0–20)
Сравнение `rock_class` с ожидаемой литологией точки:
- Совпадает с ожидаемым — 5 (подлинность подтверждена, но это норма)
- Редко для региона, есть правдоподобный механизм (пемза приплыла морем, ледниковый валун) — 20, тег «Странник»
- Не совпадает и механизма нет — 0, карточка уходит на ревью (антифрод)

### 6.3 Состав (0–45)
Базовая порода: балл считается из литологии точки — доля площади в радиусе водосбора, занятая этой породой, переводится в бакет (доминирующая 5 / обычная 10 / редкая 20 / единичная 30). Отдельно фиксированные бонусы для классов, редких везде: агат 30, окаменелость 40.
Плюс включения, каждое считается только при `confidence ≥ 0.6`:
- следы — 3, заметно — 7, основной — 12
- Множители за «красивые» включения: миндалины с цеолитом ×1.5, кварцевая друза ×1.5, пирит ×1.3, окаменелость ×2.
Потолок слоя — 45.

### 6.4 Раскрытие и качество (0–10)
- Свежий скол с видимым интерьером — 6
- Есть фото с масштабом — 2
- Пользователь прошёл мини-тесты (вес, царапина) — 2

### 6.5 Что важно
- Все числа — редакционные таблицы, не модель. Баланс правится без переобучения.
- Confidence ниже порога → включение не засчитывается вообще, а не даёт «немного».
- Одинаковый камень при пересъёмке в разных условиях должен попадать в тот же тир в ≥ 90% случаев — это метрика качества скана, отслеживается.

## 7. Механика раскола

- Если у камня форма ≤ 8 и нет включений — приложение предлагает расколоть: «Снаружи обычный, внутри может быть что-то».
- После раскола — второй скан, карточка переходит в состояние «раскрытый», состав пересчитывается. Обычно score растёт; иногда падает (внутри пусто) — это честный риск.
- Раскол необратим: закрытая версия карточки исчезает, остаётся раскрытая с пометкой «была раскрыта». Это создаёт дилемму «оставить красивую целую или рискнуть».
- Правила безопасности при первом расколе: очки, отвернуться, не бить по руке. Один экран, не пропустить.

---

## 8. Коллекция и дневник

- **Дневник локации** — список пород и включений, которые ожидаемы в этой точке (из литологии). Найденные закрываются. Полностью закрытый дневник — значок.
- **Мировой атлас** — карта регионов, где игрок сканировал; регионы раскрашиваются по полноте дневника.
- **Витрина** — до 12 карточек, видны другим.
- Наборы: «Все миндалины Черноморского побережья», «Три странника» — редакционные и генерируемые.
- Статистика: сканов, тиров, редчайшая карточка, самая далёкая находка.

---

## 9. Сообщество и верификация

По модели iNaturalist:
- Любая карточка может быть отправлена на подтверждение. Пользователи с репутацией ≥ N голосуют «согласен / другой вариант».
- Консенсус 3 голосов при согласии с AI → статус «подтверждено», +5 к score.
- Расхождение → карточка получает вердикт большинства, AI-вердикт сохраняется в истории.
- Репутация растёт за подтверждения, совпавшие с итоговым экспертным вердиктом.
- Все подтверждённые пары (фото + вердикт) идут в собственный датасет для дообучения (см. §11).

Никаких чатов и лент на MVP. Социальное = верификация + обмен + витрина.

## 10. Оценка, NFT, рынок (фаза 2)

### Grading
- Игрок отправляет камень физически партнёру-геологу (или геологическому факультету). Тариф фиксированный.
- Эксперт даёт заключение: порода, включения, оценка сохранности 1–10. Камень запечатывается в капсулу с ID, фотографируется на стенде.
- Карточка получает статус «Оценено», score пересчитывается по экспертному вердикту, и только тогда доступна к минту.

### NFT
- Минт только для оценённых. Один физический камень = один токен. Метаданные: экспертное заключение, фото на стенде, гео, дата.
- Передача токена = передача права на физический камень (хранится у кастодиана или пересылается).
- Цель: не крипто-спекуляция, а ликвидность коллекции. Блокчейн выбирается по комиссиям, не по хайпу.

### Рынок
- Внутренние обмены карточка-на-карточку без денег — с первой версии коллекции.
- Продажа за деньги — только оценённых экземпляров. Комиссия платформы 10–15 %.
- Цена формируется аукционом или фиксированным лотом; редкость и тир — ориентир, не фиксированная цена.

## 11. Данные и модель

### Геологические слои (открытые)
- Macrostrat API — глобальная литология по координатам.
- OneGeology / национальные геологические службы — детальные карты по странам.
- Mindat — известные минералы по локальностям.
- OpenStreetMap — водосборы, береговые линии (для механики «странник»).

### Модель
- **MVP:** готовая vision-LLM (Claude / GPT / Gemini) со структурированным выводом и промптом, который включает геоконтекст. Без обучения. Стоимость на скан — контролировать, при росте кэшировать похожие фото по perceptual hash.
- **v1:** собственный датасет из подтверждённых сканов (§9). Дообучение лёгкого классификатора для быстрого предварительного вердикта, LLM — для лора и спорных случаев.
- **Никогда:** проценты состава по фото. Только бакеты.

### Антифрод
- Perceptual hash против повторного скана одного камня и против фото из интернета (обратный поиск по индексу известных стоковых изображений минералов).
- Гео-аномалия: эпический камень в точке, где порода невозможна, — авторевью.
- Скан фото с экрана: детектор муара / рамки экрана.
- Лимит сканов в час для новых аккаунтов.

## 12. Экраны MVP

1. Камера/скан
2. Результат скана
3. Карточка
4. Коллекция (сетка) + дневник локации
5. Карта
6. Профиль (статистика, витрина)
7. Верификация (очередь на подтверждение)

Обмен, рынок, grading, NFT — не в MVP.

---

## 13. Монетизация

- Бесплатно: 10 сканов в день, полная коллекция.
- Подписка: безлимитные сканы, расширенный лор, экспорт коллекции, ранний доступ к grading.
- Grading — платная услуга, маржа с партнёром.
- Комиссия рынка (фаза 2).
- Не делать: платные лутбоксы, покупка редкости за деньги. Редкость только через находку — иначе рушится вся идея.

## 14. Фазы

**MVP (8–10 недель)**
Скан → карточка → коллекция → дневник локации. LLM без обучения. Запуск сразу глобально: геослои (Macrostrat, OneGeology) покрывают весь мир, модель не привязана к региону. Что при этом делается по-другому:
- Таблица частотности пород (§6.3) считается автоматически из литологии точки, а не пишется редакцией по регионам: чем меньше площадь региона с такой породой в радиусе водосбора, тем выше базовый балл.
- Дневник локации генерируется из геослоя на лету для любой точки; редакционные наборы (§8) — только для 5–10 стартовых хотспотов.
- Тестовый набор фото до запуска (§16) собирается с 3–4 разных типов геологии (вулканическая галька, известняковое побережье, гранитные реки, ледниковые валуны), а не с одного пляжа.
- Локализация интерфейса: английский + русский на старте, лор генерируется на языке пользователя.

Метрика успеха: доля сканирующих второй день, доля расколотых камней.

**v1 (+3 мес)**
Верификация сообществом, обмен, мировой атлас, собственный датасет и лёгкий классификатор. Точечный маркетинг в 3–5 регионах с известным rockhound-сообществом (США, Австралия, UK, Япония) — продукт уже глобальный, меняется только фокус продвижения.

**v2 (+6 мес)**
Grading с партнёрами, рынок, NFT. Только если коллекционный сегмент показал удержание.

---

## 15. Метрики

- Скан → карточка в коллекции: ≥ 60 %
- Возврат на 2-й день: ≥ 35 %, на 7-й: ≥ 15 %
- Доля сканов с расколом: ≥ 20 % (показывает, что механика риска работает)
- Стабильность тира при пересъёмке: ≥ 90 %
- Доля карточек, отправленных на верификацию: ≥ 10 %
- Стоимость скана (API) ≤ $0.03 при MVP

## 16. Риски и открытые вопросы

- **Точность модели на «грязных» фото.** Митигируется бакетами, порогами и верификацией, но первое впечатление формирует один плохой вердикт. Нужен тестовый набор из 200 реальных пляжных фото до запуска.
- **Экология и закон.** В ряде мест (нацпарки, заповедники, некоторые пляжи) сбор камней запрещён. Приложение должно предупреждать по гео и не начислять score в запрещённых зонах.
- **Раскол и травмы.** Экран безопасности обязателен, ответственность в EULA.
- **Grading-партнёры.** Без них фаза 2 невозможна; искать геологические факультеты и лаборатории, которым интересен поток образцов.
- **Юрисдикция NFT.** Решить на этапе v2, не раньше.
- **Название.** Lithos — заглушка, проверить на занятость в сторах и доменах.
